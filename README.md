# Менеджер контактов
Консольное приложение на C++ для управления списком контактов, оно позволяет добавлять контакты, смотреть уже добавленные контакты и удалять их. Все данные сохраняются в текстовый файл. 
Так как моя сборка Windows некорректно работает с выводом русского языка в консоль, способы управления внутри приложения написаны на английском языке.

## Доступные функции
1. Add new contact - Добавление контакта (имя, телефон, email)
2. Show all existing contacts - Просмотр всех контактов
3. Find contact by name - Поиск контакта среди существующих по имени
4. Find contact by number - Поиск контакта среди существующих по номеру телефона
5. Delete contact by name - Удаление существующего контакта по имени
0. Exit - Выход
