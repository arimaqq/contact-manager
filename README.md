# Менеджер контактов
Консольное приложение на C++ для управления списком контактов, оно позволяет добавлять контакты, смотреть уже добавленные контакты и удалять их. Все данные сохраняются в текстовый файл. 
Так как моя сборка Windows некорректно работает с русским языком, способы управления внутри приложения написаны на английском языке.

## Доступные функции
Add new contact - Добавление контакта (имя, телефон, email)
Show all existing contacts - Просмотр всех контактов
Find contact by name - Поиск контакта среди существующих по имени
Find contact by number - Поиск контакта среди существующих по номеру телефона
Delete contact by name - Удаление существующего контакта по имени
Exit - Выход

### Windows (MinGW / GCC)
g++ -std=c++11 -o ContactManager.exe main.cpp Contact.cpp ContactManager.cpp
./ContactManager.exe
